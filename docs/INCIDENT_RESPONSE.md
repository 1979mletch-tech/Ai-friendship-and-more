# Incident Response

For suspected account/data/secret exposure:
1. Stop or restrict the affected deployment.
2. Preserve relevant non-sensitive evidence.
3. Rotate affected provider/service credentials.
4. Identify exact commit, environment and affected data classes.
5. Correct authorization/RLS/server validation before restoration.
6. Re-run cross-account and abuse tests.
7. Follow applicable legal/provider notification requirements.
8. Document cause, fix, verification and prevention.

Do not place conversation content or credentials into public incident reports.
