# Chat Quality Matrix

Evaluate without turning subjective preference into a safety claim:
- warm general conversation
- concise direct response
- creative brainstorming
- context continuity within bounded recent history
- companion name personalization
- no fake-human identity
- no repetitive canned response when live AI is enabled
- graceful fallback when disabled
- no dependency manipulation
- appropriate refusal of secret/system prompt requests

Keep examples synthetic and non-private.
