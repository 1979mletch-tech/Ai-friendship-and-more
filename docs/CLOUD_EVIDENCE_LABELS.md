# Cloud Evidence Labels

Use only:
- CODE BUILT: implementation exists in source.
- CI VERIFIED: exact source SHA passes automated repository gates.
- CONFIGURED: deployment has required public/server configuration.
- LIVE TESTED: behavior was exercised against the deployed service.
- NOT CONFIGURED: deployment cannot exercise the feature.
- NOT YET TESTED: configuration may exist but no live evidence has been recorded.

Never translate CONFIGURED into LIVE TESTED.
