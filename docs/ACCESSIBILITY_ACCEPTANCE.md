# Accessibility destructive-action acceptance

Conversation deletion buttons must expose the conversation title to assistive technology. Memory deletion buttons must expose the memory label. Busy destructive actions are disabled. Sync, billing and deletion status changes use live/status or alert semantics where appropriate.

Before launch verify keyboard-only navigation, visible focus, logical focus order, screen-reader names, 200% zoom, narrow mobile width, reduced-motion behavior and destructive confirmation/error states on the exact deployed SHA.
