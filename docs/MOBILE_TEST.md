# Mobile Test Matrix

Test current Chrome/Android and Safari/iOS where available:
- 320/360/390/430px widths
- portrait/landscape
- navigation scrolling
- consent and chat composer
- keyboard open/close
- long messages
- History/Memory/Settings/Account/Privacy
- data export
- confirmation dialogs
- 200% zoom
- offline/network failure recovery

Record device/browser/version. Simulated responsive checks must be labelled simulated, not physical-device tested.
