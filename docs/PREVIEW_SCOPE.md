# Preview Scope

The first tappable preview may demonstrate the complete local UI even if cloud services are not configured.

A static preview can verify rendering, navigation, responsive layout, local chat fallback, local memory/history, pricing preview, privacy controls and immersive placeholder boundaries.

It cannot by itself verify Supabase authentication, RLS isolation, Edge Functions, OpenAI provider behavior, account deletion, Stripe checkout or webhook entitlements. Those require configured live services and separate evidence.
