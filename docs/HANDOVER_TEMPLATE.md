# Release Handover Template

Record:
- branch and exact commit SHA
- working tree/source status
- CI run URL/result
- staging URL/deployment ID
- migrations applied
- Edge Functions deployed
- auth test result
- two-account isolation evidence
- live AI result
- safety/adversarial result
- privacy/data deletion/export result
- mobile/accessibility result
- known limitations
- required environment variable names (never values)
- rollback target
- remaining production configuration

Use evidence labels: LIVE TESTED / AUTOMATED TESTED / CODE VERIFIED / SIMULATED / NOT TESTED / BLOCKED.
