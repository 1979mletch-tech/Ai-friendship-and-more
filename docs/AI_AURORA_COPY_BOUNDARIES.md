# Public Copy Boundaries

Allowed positioning includes AI companion, conversation, reflection, creativity, brainstorming, project continuity and user-controlled memory where the implementation supports it.

Do not market Aurora as human, conscious, a therapist, a replacement for people, always available in a guaranteed sense, guaranteed confidential/private, clinically safe, or emotionally exclusive. Do not use dependency-building language such as “only friend you need” or “never leave you.”
