# Definition of Done

A feature is done only when:
- implementation is complete with no intentional dead control;
- input/error/empty/loading states are handled;
- relevant automated tests exist;
- lint/typecheck/build remain green;
- privacy/security impact is reviewed;
- documentation reflects actual behavior;
- live-dependent behavior is tested in staging before being called verified.

The project is launch-ready only when launch gates are separately satisfied.
