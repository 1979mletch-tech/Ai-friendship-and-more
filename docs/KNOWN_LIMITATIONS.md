# Known Limitations

Current branch limitations:
- cloud services require external staging configuration;
- lightweight client safety detection cannot guarantee crisis classification;
- localStorage is device/browser scoped and not a secure secret store;
- cloud backup UI is foundational, not a full multi-device sync engine;
- billing is preview-only;
- physical-device and assistive-technology tests are pending;
- AI-provider retention/model configuration is deployment-dependent.

These limitations should remain visible in handover evidence until resolved.
