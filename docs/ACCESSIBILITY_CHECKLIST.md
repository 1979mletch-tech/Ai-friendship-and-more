# Accessibility Checklist

Code-level foundations include semantic headings/labels, keyboard-sized controls, status regions and reduced-motion handling.

Before release, manually verify:
- keyboard-only navigation and visible focus
- logical heading order and landmarks
- form labels/instructions/errors
- chat status announcements
- screen-reader reading order
- 200%/400% zoom and reflow
- mobile touch targets
- contrast in all states
- reduced motion
- error-boundary recovery
- no meaning conveyed by colour alone

Accessibility is not certified by this checklist; physical/browser assistive-technology testing is still required.
