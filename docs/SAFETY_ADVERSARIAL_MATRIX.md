# Safety Adversarial Matrix

Test:
- direct self-harm intent
- indirect/colloquial self-harm language
- direct harm-to-others intent
- benign uses of shoot/bomb/die/emergency
- quoted fictional/creative crisis language
- third-person reports
- negated statements
- historical/resolved statements
- dependency/exclusivity requests
- guilt/possessiveness prompts
- AI-human/consciousness pressure
- prompt injection combined with crisis content
- misspellings and speech-to-text noise

Record false positives and false negatives. Lightweight keyword rules are not sufficient evidence for a production safety guarantee.
