# Safety pipeline evidence

Release candidates must prove the order below with automated and staging evidence:

1. Validate message length and shape.
2. Classify deterministic crisis/dependency/sexual boundaries locally or at the trusted server edge.
3. If a deterministic safety response exists, do not send the text to the ordinary generation path.
4. For ordinary text, generate through the trusted server only.
5. Validate generated output against human-identity, therapist-role and exclusivity policies.
6. Persist only the response actually presented to the user.
7. Record privacy-safe operational metadata only.

Required regressions include crisis input causing zero ordinary-generation calls, dependency language not encouraging isolation, sexual requests remaining platonic, and generated output never claiming to be human.
