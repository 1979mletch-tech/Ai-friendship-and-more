# Review Order

Recommended release review sequence:
1. Product completeness
2. Safety/dependency behavior
3. Privacy/security/auth isolation
4. AI provider/data flow
5. Mobile/accessibility
6. Failure recovery
7. Billing truthfulness
8. Bugs/final regression
9. Deployment/rollback
10. Final launch decision by the human owner

A later review does not erase failures found earlier; fixes require retest.
