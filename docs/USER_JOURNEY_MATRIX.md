# User Journey Matrix

Core journeys to verify end-to-end:
1. first visit → disclosure/consent → general chat
2. first visit → creative chat
3. memory add → view → forget → clear
4. history view/search/clear
5. companion settings
6. account create/sign-in/recovery/sign-out
7. cloud backup and later retrieval design
8. privacy → export → local delete
9. account permanent delete
10. crisis/dependency/injection safety
11. network/provider failure fallback
12. mobile navigation

Each journey needs an explicit result on the deployed candidate.
