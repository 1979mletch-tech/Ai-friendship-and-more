# Phone Preview Acceptance

Test the deployed preview on a real phone before calling the preview verified.

- Page opens over HTTPS without browser warnings.
- Header/navigation is usable without clipped controls.
- All tap targets remain comfortably tappable.
- Chat input is visible when keyboard opens.
- Send does not double-submit.
- Long assistant replies scroll correctly.
- History and Memory lists do not overflow horizontally.
- Account form uses appropriate email/password keyboard behavior.
- Pricing cards stack cleanly.
- Privacy controls are reachable.
- Orientation change does not lose local state.
- Offline state does not claim cloud success.
- Reload preserves intended local state.
- Text zoom and system font enlargement remain usable.

Record device/browser/version and PASS/FAIL for each item.
